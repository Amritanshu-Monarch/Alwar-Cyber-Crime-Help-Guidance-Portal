# Instagram Account Hacking

## How Accounts are Compromised
- Phishing links disguised as copyright infringement warnings or influencer brand collaboration deals.
- Asking victims to forward a password reset link or screenshot containing a verification code.
- Reusing leaked passwords without Two-Factor Authentication (2FA).

## Recovery Steps
1. Go to Instagram login page -> click "Forgot password?" -> enter username -> request secure login link.
2. If email/phone was changed by hacker, select "Need more help?" -> submit video selfie verification to Instagram.
3. Check email for a message from security@mail.instagram.com stating "Email address changed". Click "Revert this change" or "Secure your account here".
4. Once recovered, enable 2FA using an Authenticator app and log out of all unauthorized sessions.
